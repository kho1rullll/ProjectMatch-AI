1. GAMBARAN UMUM DAN PENJELASAN SISTEM
1.1 Latar Belakang Masalah
Fenomena pengangguran terdidik di Indonesia telah mencapai 1,03 juta orang (sekitar 14,31% dari total pengangguran nasional) berdasarkan data Badan Pusat Statistik (BPS). Faktor pemicu utamanya adalah ketidaksesuaian keterampilan (skill mismatch) yang memengaruhi lebih dari 50% hingga 72,3 juta tenaga kerja (Mandiri Institute). Di lingkungan akademis, proses penyaringan portofolio mahasiswa oleh mitra industri maupun dosen peneliti masih dilakukan secara manual dan berpatokan pada parameter administratif formal seperti IPK, yang belum merepresentasikan keterampilan spesifik (niche skills) dan pengalaman riil berbasis proyek.
1.2 Solusi ProjectMatch AI
ProjectMatch AI hadir sebagai ekosistem link-and-match cerdas berbasis web, Artificial Intelligence (AI), Internet of Things (IoT), dan Multimedia Interaktif. Sistem ini memetakan kualifikasi proyek industri dengan portofolio non-terstruktur mahasiswa menggunakan Large Language Model (LLM) dan Recommendation System berbasis semantic matching. Aksesibilitas sistem diperluas ke ruang fisik kampus melalui terminal Smart Campus Kiosk (berbasis RFID KTM) untuk otentikasi cepat, serta didukung visualisasi multimedia interaktif bergaya status hero RPG/game untuk pengalaman pengguna yang komunikatif dan responsif.
1.3 Indikator Keberhasilan & Target Kinerja
Akurasi AI Semantic Matching: 
Mencapai ≥ 85% pada pengujian User Acceptance Testing (UAT).
Waktu Pemrosesan Rekomendasi: 
Berjalan secara real-time (< 1 menit per pencarian/pindaian).
Keberhasilan RFID Kiosk: 
Tingkat pembacaan identitas kartu RFID pada terminal IoT ≥ 95%.
Kepuasan Pengguna (User Satisfaction): 
Skor kepuasan antarmuka pengguna minimal 4.0 / 5.0.

3. FITUR-FITUR UTAMA SISTEM
Manajemen Profil & Portofolio Mahasiswa: 
Modul pengunggahan CV/resume berbasis PDF, penautan repositori GitHub, serta ekstraksi riwayat proyek berbasis project-based learning secara otomatis.
Manajemen Lowongan Proyek Mitra: 
Antarmuka pembuatan deskripsi proyek oleh mitra industri/dosen yang secara otomatis diekstraksi kriteria skill-nya menggunakan LLM.
AI Semantic Matching Engine: 
Mesin utama berbasis AI yang menghitung nilai relevansi semantik antara kualifikasi proyek dengan portofolio mahasiswa secara kontekstual.
Smart Campus Kiosk (IoT Integration): 
Terminal fisik berbasis ESP32 dan RFID Reader RC522 di area kampus untuk autentikasi KTM instan dan penyajian rekomendasi proyek secara cepat di layar kiosk.
Visualisasi Data Interaktif & Gamified Multimedia: 
Grafik segi lima/segi enam interaktif (jaring laba-laba/radar chart) bergaya status hero game yang dapat disentuh/diklik (drill-down tooltip) serta ditumpuk otomatis (overlay matching) untuk analisis kecocokan proyek.
Dasbor Analitik & System Notification: 
Dasbor peringkat kandidat bagi mitra industri serta notifikasi real-time skor kecocokan proyek bagi mahasiswa.

4.2 Tiga Pilar Interaktivitas Grafik Kompetensi
Antarmuka grafik status pada ProjectMatch AI dirancang dengan tiga mekanisme interaksi utama:
1. Touch/Click Interactive Drill-down (Tooltips Bukti Portofolio): 
Saat pengguna menyeleksi atau men-tap titik simpul kemampuan tertentu (misalnya bagian 'Koding'), grafik akan melakukan efek fokus/zoom dinamis dan menampilkan kartu informasi pop-up (tooltip context). Sistem tidak hanya menunjukkan angka, tetapi juga alasan di balik nilai tersebut (contoh penjelasan: 'Nilai Koding: 90 — Didasarkan pada repositori GitHub web toko online & proyek sistem informasi').
2. Automatic Overlay Skill-to-Project Matching (Visualisasi Penumpukan Grafik): 
Saat mahasiswa memilih atau melihat detail sebuah lowongan proyek, grafik kemampuan diri mahasiswa (berwarna terang/kontras) akan secara otomatis ditumpuk (*overlaid*) di atas grafik kualifikasi ideal yang diminta oleh proyek mitra (berwarna semi-transparan). Mahasiswa dapat mengevaluasi kesesuaian secara instan secara visual: jika bentuk kedua grafik saling berhimpitan secara presisi, maka tingkat kecocokan proyek sangat tinggi.
3. Dynamic Micro-interactions & Direct Touch Feedback: 
Grafik memberikan umpan balik langsung (haptic/visual feedback) seperti efek glowing pada area yang cocok, pergeseran sudut secara halus, dan animasi pergerakan area saat kriteria dipilh atau disaring.

6. INTEGRASI ARTIFICIAL INTELLIGENCE DAN ALGORITMA MATCHING
6.1 Ekstraksi Kriteria Proyek (LLM via Ollama)
Sistem memanfaatkan Ollama yang menjalankan model bahasa open-source (Qwen / Llama) secara lokal. Saat mitra industri memasukkan deskripsi proyek, LLM akan melakukan prompt parsing untuk mengekstraksi kualifikasi kunci (seperti 'Python', 'FastAPI', 'UI/UX Design', 'Data Analysis') dan tingkat pengalaman yang dibutuhkan secara terstruktur.
6.2 Vector Embedding (Sentence Transformers)
Dokumen portofolio/resume mahasiswa dan deskripsi kebutuhan proyek dikonversi menjadi bentuk vektor numerik menggunakan Sentence Transformers. Representasi vektor ini menyimpan konteks arti kata (semantic context), sehingga kata yang memiliki makna mirip (misal: 'Web Developer' dan 'Frontend Engineer') berada di posisi berdekatan dalam ruang vektor.
6.3 Perhitungan Skor Kesesuaian (Cosine Similarity)
Tingkat kecocokan antara vektor portofolio mahasiswa (A) dan vektor proyek (B) dihitung menggunakan rumus Cosine Similarity:
Similarity Score (A, B) = ( A • B ) / ( ||A|| × ||B|| )
Hasil perhitungan menghasilkan nilai rentang 0.0 hingga 1.0 (0% - 100%). Nilai skor ini dipetakan secara real-time ke antarmuka pengguna dalam bentuk persentase kecocokan dan grafik radar keahlian (Skill Radar Chart) untuk proses penumpukan (overlay).
7. SPESIFIKASI API (APPLICATION PROGRAMMING INTERFACE)
Arsitektur sistem ProjectMatch AI menghubungkan berbagai subsistem melalui tiga jenis antarmuka API:
FastAPI REST API: 
Mengelola transaksi data utama antara web frontend dan backend. Endpoint mencakup:
• POST /api/v1/auth/login : Otentikasi pengguna & pembuatan JWT Token.
• POST /api/v1/profiles/resume : Pengunggahan berkas PDF CV & ekstraksi portofolio.
• POST /api/v1/projects : Pembuatan lowongan proyek baru oleh mitra.
• GET /api/v1/recommendations/{mahasiswa_id} : Pengambilan rekomendasi proyek teratas & data titik koordinat radar chart.
WebSocket / IoT API: 
Menyediakan jalur komunikasi duplex real-time antara mikrokontroler ESP32 Smart Kiosk dan server backend. Saat kartu RFID (KTM) di-tap pada kiosk, data UID dikirimkan via endpoint WS /ws/kiosk/{device_id} sehingga sistem langsung menampilkan profil dan grafik radar interaktif di layar Kiosk dalam waktu < 1 detik.
Ollama Local API: 
Interface internal backend ke service Ollama melalui endpoint POST http://localhost:11434/api/generate untuk melakukan eksekusi prompt LLM secara terisolasi.
